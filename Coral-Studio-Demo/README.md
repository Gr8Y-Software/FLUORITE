# Coral Studio Demo

A responsive, four-page sample site built with Coral Studio. The demo showcases a dark visual theme, reusable page layouts, Markdown card sections, a mobile navigation menu, and generated site metadata.

## Pages

- **Overview** — introduces the workspace and its core benefits.
- **The studio** — tours the main editing and preview tools.
- **Workflow** — walks through creating, building, and publishing a site.
- **About** — explains the ideas behind Coral Studio.

## Open and preview

1. In Coral Studio, choose **Open project** and select the `Coral-Studio-Demo` folder.
2. Select **Build site** to regenerate the static pages in `dist/`.
3. Open **Preview** and browse the generated pages.

The source Markdown lives in `data/`, the page layouts in `layouts/`, and the styles and menu behavior in `styles/site.css` and `scripts/site.js`.
