## The best tools make space for the work.

Coral Studio is for designers, writers, and developers who want a capable place to build without carrying the weight of a large platform.

It brings together the practical parts of making a website—content, code, assets, builds, and previews—in a clear desktop workspace.

### Thoughtful by default

- **Fast sites:** static output keeps pages lightweight and easy to host.
- **Your files:** work directly with the source and keep control of your project.
- **Less context switching:** move from writing to code to preview in one place.

Coral Studio is a work in progress, shaped around a simple idea: the tools should help your best work come through.
