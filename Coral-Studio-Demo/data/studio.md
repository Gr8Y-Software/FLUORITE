## One workspace. All the important parts.

Coral Studio keeps the moving pieces of a static site close at hand, without getting between you and the work.

::: card
### Code
Work in your project files with syntax highlighting, line numbers, and a distraction-free editor.
:::

::: card
### Markdown
Write naturally, shape your content, and preview the reading experience as you go.
:::

::: card
### Structure & data
Keep JSON settings and page structure understandable and easy to maintain.
:::

::: card
### Media
Browse images, audio, and video alongside the pages where they belong.
:::

::: card
### Preview
Check built pages at desktop, tablet, and phone widths before sharing.
:::

::: card
### Terminal
Run your project commands from the same workspace as your source.
:::

## Your files stay yours

A Coral Studio project remains a regular folder of files. Open it in another editor, keep it in version control, or build it from the command line whenever you like.
